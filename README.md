# 🎮 JavaScript Quest

> A one-week intensive JavaScript course for first-year university students —
> taught as a game of blocks, tasks, boss challenges, and XP.

Beginners go from `console.log("Hello")` to building a full interactive web app
in five days. No prior programming experience required.

---

## 🚀 Quick Start (Students)

1. **Download or clone** this repository:
   ```bash
   git clone https://github.com/rishopbabu-iOSDEV/introduction-to-programming-js.git
   ```
2. Open the folder in **VS Code** and install the **Live Server** extension.
3. Go to [`starter/`](starter/) and open the first task:
   `starter/block-1-basics/task-1-1-hello-world/`.
4. Right-click `index.html` → **Open with Live Server**, then press **F12**
   to open the Console.
5. Follow the `// TODO` comments in `app.js`. Stuck? The finished version is in
   [`solutions/`](solutions/).

## 🎯 How to Use This Repo

### For Students
- Work in [`starter/`](starter/) — follow the `// TODO` steps in each `app.js`.
- Try the task yourself first. If stuck for more than ~10 minutes, read the
  comments (not the whole solution).
- Compare against [`solutions/`](solutions/) once you have an attempt.
- On Friday, build your own **final project** — study the four apps in
  `solutions/block-7-projects/` for ideas.

### For Instructors
- Start with [`tutor-handbook/TUTOR_HANDBOOK.md`](tutor-handbook/TUTOR_HANDBOOK.md) —
  a topic-by-topic guide on how to drive each class engagingly, with real-world
  examples and a student-doubts bank. Written for a tutor who knows programming
  but is new to JavaScript.
- `solutions/` files are **answer keys** — reveal them only after students attempt a task.
- Each solution is commented *as if talking to a beginner*, and ends with a
  `✅ What to try next:` section for fast finishers.
- Blocks 1–5 run in the browser Console (or with Node.js); Blocks 6–7 are full
  HTML pages — open with **Live Server**.
