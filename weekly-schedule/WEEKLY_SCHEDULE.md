## 📋 Instructor Daily Prep Checklist

### Before Each Day
- [ ] Update class leaderboard from previous day
- [ ] Prepare the day's live-coding examples (test them — no surprises!)
- [ ] Check that classroom projector + VS Code font size is readable (min 18px)
- [ ] Have the day's answer keys ready (but don't show them yet)

### During Class
- [ ] Start each morning with a 15-min recap quiz (verbal)
- [ ] Walk the room every 20 minutes during practical sessions
- [ ] Note students who finish early → assign bonus XP tasks
- [ ] Note students who are stuck → pair them with a classmate first, help second

### End of Each Day
- [ ] Update XP tracker for all students
- [ ] Post leaderboard (on whiteboard or shared screen)
- [ ] Award any badges earned that day
- [ ] Quick anonymous poll: "What was confusing today?" (sticky notes or Google Form)
