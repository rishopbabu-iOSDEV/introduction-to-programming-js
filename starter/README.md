# 🚀 Starter Files — Start Here

This folder is **your workspace**. Every `app.js` here is a guided stub with
`// TODO:` steps and hints — but no finished code. Your job is to fill them in.

## How to work through a task

1. Open a task folder (e.g. `block-1-basics/task-1-2-profile-card/`).
2. Read the comment header — it tells you the concept and the goal.
3. Follow the `// TODO` steps one at a time.
4. Run your code:
   - **Blocks 1–5** (Console tasks): open the folder's `index.html` with the
     **Live Server** extension in VS Code, then press **F12** to see the Console.
     (Tasks without an `index.html` can also be run with `node app.js`.)
   - **Block 6** (web pages): open `index.html` with **Live Server**.
5. Stuck for more than ~10 minutes? Peek at the matching folder under
   [`../solutions/`](../solutions/) — but try first!
